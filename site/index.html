蔵貫について

宇和海に面した、浜と山の集落

蔵貫（くらぬき）は、西予市三瓶町の三瓶湾のなかほど、三島川が宇和海に注ぐところにある地区です。海に面した「蔵貫浦（くらぬきうら）」と、川をさかのぼった山あいの「蔵貫（蔵貫村）」の二つの集落からなります。江戸時代には蔵貫村が宇和島藩、蔵貫浦が吉田藩に分かれていましたが、三島神社の秋祭りは今も浦と村がいっしょに行っています。

2026年、地域の皆さんと西予市、愛媛大学が一緒に「蔵貫フットパス」をつくりました。神社やお寺、めだかの里をめぐりながら、避難場所の位置も自然に覚えられるコースです。

          フットパスのルール

          1. 川・水路・海・道ばたに、ゴミをポイ捨てしないようにしましょう。
          2. メダカなど水辺の生き物や、田畑の作物・草花を、勝手に採取するのはやめましょう。
          3. 壁画・石碑・案内板は地域の宝物です。落書きや傷つけはやめましょう。
          4. 地域の方にあいさつをして、暮らしの迷惑にならないよう歩きましょう。
          5. 避難場所や避難路の位置を確認し、暗くなる前に歩き終えましょう。
          6. ご神木や境内の木は信仰の対象です。傷つけたり枝や葉を取ったりせず、見守りましょう。

          歩いて知る

          蔵貫の防災と歴史

          蔵貫は、海と川と急な山にはさまれた地区です。これまでに津波、豪雨による山崩れ、川の増水、大火を経験してきました。その記録と、昔の人の知恵を知ってから歩くと、同じ道がちがって見えてきます。

          蔵貫で起きた災害の記録

          1. 1854年（安政元年）安政の大地震による津波

            津波が蔵貫に押し寄せた記録があり、当時の浸水域を示す図が三瓶町誌に残っています。将来の南海トラフ地震を考えるうえでの先例です。

            出典：三瓶町誌 上巻
          2. 1882年・1926年蔵貫浦の大火

            明治15年に20戸、大正15年に22戸が焼けました。昭和2年にも出火の記録があります。家が密集した浦の集落では、火事も大きな災害でした。

            出典：三瓶町誌 上巻
          3. 1943年7月（昭和18年）記録的な豪雨による山崩れ

            大規模な山崩れで多くの家屋が土砂に押し流されました。婦人会・青年団が総出で復旧にあたりました。昭和50年代には、墓地や寺の裏の山すそで崩壊を防ぐ工事が行われています。

            出典：三瓶町誌 上巻
          4. 2018年7月（平成30年）西日本豪雨

            三島川が増水し、河口近くから上流まで数か所で護岸が壊れました。現在は復旧しています。

            出典：愛媛県西予土木事務所の資料
          5. 2026年事前復興計画とフットパス

            南海トラフ巨大地震に備えて、地区・西予市・愛媛大学で事前復興計画をつくりました。フットパスづくりはその取り組みの一つです。

            出典：三瓶南地域事前復興まちづくり計画、愛媛新聞（2026年11月4日）
          フットパスのミッション「三島川の草引き・清掃」は、こうした流木やゴミの詰まりによる氾濫を防ぐための、ふだんからできる防災です。

          昔の人の知恵

          風除け祭り

          三島神社の樹齢約500年のビャクシン（市指定天然記念物）に風の神を迎え、二百十日の7日前に作物を台風から守るよう祈った祭りです。今は行われていません。

          ナギの葉のお守り

          高神様のナギ（市指定天然記念物）の葉を、鏡の裏や「ます袋」に入れて、近年まで災難よけにしていました。

          コース上の避難場所

          歩きながら場所を確かめておきましょう。地震のあと津波が来るおそれがあるときは、海や川から離れて高いところへ逃げてください。

          蔵貫のあゆみ

          1. 768年（神護景雲2年）三島神社の創建と伝わる

            山の神をまつって建てられたと伝えられています。室町時代の末に兵火で全焼しましたが、二人の村人がご神体を守り出しました。その子孫は今も祭りで弓矢の役を務めています。

          2. 1657年（明暦3年）村と浦が二つの藩に分かれる

            蔵貫村は宇和島藩、蔵貫浦は吉田藩に。秋祭りを別々にしなければならなくなったとき、村人は和歌を藩に送り、浦と村の同時開催を認めてもらったといわれます。

          3. 1769年（明和6年）極山（きわめやま）の境界争い

            草刈り場の極山をめぐり、宇和町側の東山田村と争いました。その絵図と裁定書は町指定文化財として、歴代の区長が引き継いできました。

          4. 明治〜昭和海と山の仕事

            塩田、製糸工場、マンガン鉱山、温州みかんの段々畑、真珠やウナギの養殖など、時代ごとにさまざまな仕事が地区を支えてきました。

          浜の子どもたちの記憶

          昭和30年代ごろまで、蔵貫浦の子どもたちは、夏は浜で船の底をくぐる潜水競争をし、三島川でツガネ（モクズガニ）やエビをとって遊びました。正月3日の「天神祭り」や11月の「亥の子」は、子どもだけで計画して行う行事でした。亥の子は今も続いています。

          出典：えひめの記憶「三島川河口の子どもたち－三瓶町蔵貫浦－」、三瓶町誌 上巻

              愛媛大学の学生ら約60人がフットパスを体験しました

              2026年10月31日、愛媛大学の学生ら約60人が、地域のガイドの皆さんと一緒に二つのコースを歩きました。いくつかの班に分かれ、途中で水路のメダカ探しや海岸清掃などのミッションにも取り組みました。
