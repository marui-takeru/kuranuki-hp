# 蔵貫地区ホームページ 制作フォルダ

西予市三瓶町蔵貫地区のホームページ（フットパスを中心とした地区サイト）を作るためのフォルダです。
参考にしたのは、西予市城川町の高川地域づくり会のサイト（https://www.takagawa-shikoku.com/ ）です。

**このフォルダは、完成後に蔵貫地区の皆さんへお渡しする前提で作っています。**
専門知識がなくても中身がわかるよう、フォルダ名とファイル名は日本語にしています。

## フォルダの中身

| フォルダ | 入っているもの |
|---|---|
| `docs/` | 方針・予算・設定方法など、決めたことの記録 |
| `原稿/` | ホームページに載せる文章（ページごとに1ファイル） |
| `素材/写真` `素材/マップ` | 載せる写真とコースマップ（掲載の許可を取ったものだけ） |
| `site/` | 見た目を確認するための試作版のページ |
| `引き継ぎ/` | 地域の方向けの運営マニュアル、アカウント情報の管理表（パスワードは書かない） |
| `削除予定/` | 不要になったファイル。すぐには消さず、最後にまとめて確認します |

## 公開中のテスト用ページ（GitHub Pages）
https://marui-takeru.github.io/kuranuki-hp/

- `site/index.html` を直したら `./tools/build_pages.sh` を実行し、コミットして push すると、数分でこのページに反映されます。
- 人が写っている写真は、掲載許可が取れるまで「写真準備中」の画像で表示しています（`tools/build_pages.sh` の `HOLD` に名前を書いた写真）。
- 検索サイトには出ない設定（noindex）にしています。

## 進め方

1. 試作版を作り、テスト用のURLで地域の方に見ていただく
2. ご意見を反映し、本番の仕組み（`docs/02_運営予算と設定.md`）で公開する
3. 運営マニュアルとあわせて地域へお渡しする
