# 運営予算とおすすめの設定（2026-11-10 試算）

料金は2026年11月時点で調べた目安（税込）です。キャンペーンで変わるので、契約前に公式サイトで確認してください。

## 結論
**WordPress（ワードプレス）＋レンタルサーバー＋独自ドメイン**がおすすめです。高川と同じ仕組みです。
- 年間費用は **約1.3万円**（ドメイン代はサーバー特典で無料）
- お知らせや写真の追加を、パソコンでもスマホでも、ブログを書く感覚でできる
- 同じ西予市の高川地区に、使い方を相談できる

## 選択肢の比較（年間の費用）
| | 仕組み | 年間費用の目安 | 地域の方の更新しやすさ | 向いている場合 |
|---|---|---|---|---|
| **1（おすすめ）** | WordPress＋レンタルサーバー（例：エックスサーバー スタンダード） | **約1.2〜1.4万円**（月1,000〜1,100円前後、ドメイン1つ無料特典） | ◎ ブログ形式で更新できる | 地区全体サイトで、お知らせやブログを続けたい |
| 2 | Googleサイト（無料）＋独自ドメイン | **0〜約3,000円**（無料URLのままなら0円） | ○ 操作は簡単だが、ブログやお知らせ一覧は作りにくい | まず費用をかけずに始めたい |
| 3 | Wix など（ホームページ作成サービス） | **約1.6〜3万円**（月1,300円〜＋ドメイン代） | ○ 見た目は作りやすいが、値上げが続いている | デザインを重視したい |
| 4 | 自作のページ（GitHub Pages など） | 0円（ドメインを付けると年1,500〜3,000円） | × 更新に専門知識が必要 | 試作版の確認用（今回はここで試作） |

参考：エックスサーバー スタンダードは、12か月契約で月1,100円（キャンペーン時は990円）。12か月以上の契約と自動更新でドメインが1つ無料（2026年10月時点の公式キャンペーンページより）。

## 初期費用と、ほかにかかりうる費用
| 項目 | 目安 | 備考 |
|---|---|---|
| サーバー初期費用 | 0円 | 主要サーバーは無料のことが多い |
| WordPressのデザイン（テーマ） | 0円〜約1.5万円 | 無料テーマで十分。有料は買い切り |
| SSL（https化） | 0円 | サーバーに無料で付いている |
| バックアップ | 0円 | サーバーの自動バックアップを使う |
| 申込みフォーム | 0円 | Googleフォームを埋め込む |
| チラシ・看板に載せるQRコード | 0円 | 印刷代は別 |
| 制作・修正の外注（必要な場合のみ） | 数万円〜 | 大学側が作れば不要 |

**目安：初年度 約1.3万円、2年目以降も 約1.3万円／年**（12か月契約の場合。3年契約にすると月あたりは安くなるが、一度の支払額は増える）

## お渡しを前提にしたおすすめの設定
1. **契約は地区の団体名義にする**。大学・学生・個人の名義にしない（卒業や異動で止まらないようにする）
2. **団体専用のメールアドレスを1つ作り**（例：Gmail）、サーバー・ドメイン・WordPress・Googleフォームをすべてそのアドレスで登録する
3. **管理者は地域側に2人以上**。大学側は「編集者」の権限で手伝い、引き継ぎが終わったら外す
4. **自動更新をすべてオンにする**（サーバー契約、ドメイン、WordPress本体）。更新や支払いの通知は専用メールに届くようにする
5. **支払い方法を最初に決める**。団体のカード、請求書払い、口座振替のどれが使えるか確認する（会計年度に合わせて年払いが扱いやすい）
6. **パスワードは「引き継ぎ」フォルダに書かない**。紙に書いて2か所で保管するか、パスワード管理アプリを使う。フォルダには「何のアカウントがあるか」だけを書く
7. **写真の掲載許可の記録を残す**（撮影者、写っている人、許可を取った日）
8. **運営マニュアルを作る**（お知らせの投稿、写真の差し替え、申込みの確認、年1回の支払い確認）

## 予算の出どころ（地域の方と相談）
- 地域づくり組織や自治会の通常予算（年1.3万円程度なら収まる可能性あり）
- 西予市の地域づくり関係の補助・交付金（使えるかどうかは市に確認）
- 最初の1〜2年は、研究費などで立て替えられるかを大学側で確認
